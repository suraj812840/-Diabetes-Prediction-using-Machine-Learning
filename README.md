# -Diabetes-Prediction-using-Machine-Learning
Pima Indians Diabetes Dataset. Diabetes is a chronic disease that affects millions worldwide, and early diagnosis is critical for effective treatment and prevention of complications. The dataset used contains diagnostic measurements for 768 women of Pima Indian heritage, including features like glucose level, blood pressure, skin thicnic and more.
# 🩺 Diabetes Prediction using Machine Learning

## 📌 Project Overview

This project aims to predict the likelihood of diabetes in patients using machine learning techniques based on diagnostic health data. By training models on the Pima Indians Diabetes dataset, we identify whether a patient is likely to have diabetes or not. Early detection can help in better medical intervention and health management.

---

## 🎯 Objective

To build a predictive model that uses input features like glucose level, BMI, age, blood pressure, etc., to classify whether a person is diabetic or non-diabetic.

---

## 📂 Dataset Information

- **Dataset Name**: Pima Indians Diabetes Dataset
- **Source**: UCI Machine Learning Repository / Kaggle
- **Samples**: 768
- **Features**:
  - Pregnancies
  - Glucose
  - Blood Pressure
  - Skin Thickness
  - Insulin
  - BMI
  - Diabetes Pedigree Function
  - Age
- **Target**: Outcome (0 = Non-diabetic, 1 = Diabetic)

---

## 🔍 Workflow

1. Data loading and cleaning
2. Exploratory Data Analysis (EDA)
3. Feature scaling and preprocessing
4. Model training using:
   - Logistic Regression
   - Random Forest
   - Support Vector Machine (SVM)
   - K-Nearest Neighbors (KNN)
5. Model evaluation and accuracy comparison
6. Final predictions and visualization

---

## 📈 Accuracy Achieved

- Logistic Regression: 77%
- Random Forest: 80%
- SVM: 76%
- KNN: 78%
